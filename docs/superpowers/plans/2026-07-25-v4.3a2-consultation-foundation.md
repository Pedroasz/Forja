# V4.3A.2 consultation foundation implementation plan

> Execute only after the V4.3A.1 design is approved and merged. Use test-driven development, local Supabase only, small commits and a draft pull request. Do not apply migrations remotely or deploy production without separate explicit approval.

**Goal:** Implement the first secure, adult, linked-client professional consultation foundation for trainers and nutritionists.

**Architecture:** Relational author/subject core, RPC-only sensitive writes, server-backed editing lease, versioned measurement/formula definitions, immutable final/publication snapshots and private attachment metadata. The existing monolithic `index.html` receives only the minimal controller and screen integration after the server contracts pass.

**Stack:** PostgreSQL/Supabase migrations and RLS, Supabase CLI local tests, Node validation scripts, vanilla HTML/CSS/JavaScript.

**Design inputs:**

- [V4.3A.1 specification](../specs/2026-07-25-v4.3a1-consultation-module-design.md)
- [ADR 0003](../../adr/0003-professional-consultation-records.md)
- [Current system audit](../../audits/v4.3a1-current-professional-system-audit.md)

## Execution rules

1. Start from the then-current `origin/main`; fetch and compare paused/open branches before integrating anything.
2. Use a new `feature/v4.3a2-consultation-foundation` branch and one draft PR.
3. Confirm the approval gates in ADR 0003 before the checkpoint that depends on them.
4. Begin every behavioral slice with a failing focused test.
5. Enable RLS at table creation, even when policies arrive in the next checkpoint; no temporary authenticated access.
6. Keep browser writes behind RPCs and derive actor/subject server-side.
7. Run the available migration and workspace validators before every push.
8. Push each validated A.2 checkpoint and update the same draft PR.
9. Keep migrations local until a separate remote-apply approval.
10. Keep Diet, food catalog, real data, Vercel/production and unrelated app behavior unchanged.

Run after each checkpoint:

